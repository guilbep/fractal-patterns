# Speed, phase 11: genes, Breed, the gallery, the page footprint

## What changed

Phase 11 adds:
- named genes for the random draws in the Wallpaper Studio, carried in the link key `g`,
- the Breed fold in the Studio, which grows children in a module Web Worker,
- a gallery generator script (`make gallery`), which runs at build time only,
- a footer line with the page's own CO₂ footprint, on the three pages.

The genes and the footer line load at start. The Breed fold and its worker load on demand: when the fold opens for the first time, it loads. When it grows children, the worker starts.

## How to measure

Run `make perf`. It builds the site for production, serves it with `vite preview`, and runs Lighthouse (mobile) 3 times per page. The tables give the median.

Start JavaScript is the sum of the gzip sizes (default level) of the script and modulepreload files that each `dist/*.html` lists.

All numbers come from the production build, on one machine, on the same day.

## Breed timings

The orchestrator measured these, not this note's author. Production build, Chromium, with Playwright.

| Viewport | CPU | 9 children grown in | Long tasks while they grew |
|---|---|---:|---|
| 1440 px | no throttling | 178 ms | none |
| 360 px | 4× slower | 228 ms | one of 60 ms |

The cause of the 60 ms task is not isolated. When a child is used, the main thread composes the wallpaper, as before phase 11.

## The gallery generator

`node scripts/studio-gallery.ts` printed "wrote 63 cells … in 27630 ms" on one desktop. It runs at build time only. It costs visitors nothing.

## What the numbers show

Studio loads 1.7 kB more JavaScript at start. Phase 11 adds the genes, the loader of the Breed fold and the footer line to it. Patterns and Builder load about 0.3 kB more. The footer line is the main phase 11 change on those two pages.

Each page stays under the phase limit of 2 kB more than the previous phase. Studio is close to it.

When a visitor opens the fold, the Breed fold and its worker load (about 23 kB gzip together). Before that, they cost nothing.

The scores do not change. The layout shift is 0.000 on the three pages.

The total blocking time varies from run to run, also on an unchanged build. Builder FCP is 163 ms slower and its TBT 27 ms lower. These numbers do not prove a change in either.
