# Speed, phase 5a: the new look and the shared parts

## What changed

Phase 5a changes these things on the three pages:
- new color tokens and the Truchet logo,
- shared controls: a switch, a segmented control, a file drop zone,
- one size badge wording and one toolbar order,
- undo in the Studio, and a keyboard panel behind a "?" button.

The keyboard panel loads on demand, as plain TypeScript with no Vue import. A first version used a Vue component that loaded on demand. That split the Vue runtime out of the shared chunk and added 1.5 to 2 kB to each page, so it was rebuilt.

## How to measure

Run `make perf`. It builds the site for production, serves it with `vite preview`, and runs Lighthouse (mobile) 3 times per page. The tables give the median.

Start JavaScript is the sum of the gzip sizes (default level) of the script and modulepreload files that each `dist/*.html` lists.

All numbers come from the production build, on one machine, on the same day.

## A layout shift, found and fixed

The first measure of phase 5a gave the Studio a score of 87 and a layout shift (CLS) of 0.219.

The size badge first reads "compressing". When the real size arrives, the badge grows wider. On a phone it then pushed the next toolbar items onto a new row, and the page moved down by 45 px.

The badge now reserves the width of its final text from the first paint: 18em, 16.5em below 480 px, and 14em on the Patterns page below 400 px, where the unit hides. The layout shift is now 0.000 on the three pages.

## What the numbers show

The pages stay at a score of 99. Each page loads more code, but all three stay inside the limit of 2 kB for the phase. The Builder has the least room left, about 110 bytes.

The total blocking time varies from run to run, also on an unchanged build. These numbers do not prove a change in it.
