# Speed, phase 5b: the "Use it" panel

## What changed

Phase 5b adds the "Use it" panel to the three pages:
- eight destinations with size presets and a how-to line,
- a device preview for each destination,
- a PNG download at the chosen size.

The "Use it" panel loads at start on every page. The PNG renderer (`src/png-export.ts`) loads on demand, at the first PNG download.

## How to measure

Run `make perf`. It builds the site for production, serves it with `vite preview`, and runs Lighthouse (mobile) 3 times per page. The tables give the median.

Start JavaScript is the sum of the gzip sizes (default level) of the script and modulepreload files that each `dist/*.html` lists.

All numbers come from the production build, on one machine, on the same day.

## What the numbers show

Each page loads about 7 kB more JavaScript at start. That is the "Use it" panel and its device preview.

The PNG renderer is not in these numbers. It loads at the first PNG download.

The scores stay at 98 or 99. The layout shift stays at 0.000 on the three pages.

The total blocking time varies from run to run, also on an unchanged build. These numbers do not prove a change in it.

The owner decided that the page size does not limit the design. The size is measured and reported here, and cuts are decided at the end.

## A possible saving for the final review

Load the "Use it" panel on demand, at the first click on "Use it…" or on the tab. That can save about 7 kB of start JavaScript on each page.
