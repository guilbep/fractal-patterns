# Speed, phase 7 (Ornament engine)

## What changed

Phase 7 adds:
- the periodic tilings and the "Star patterns" family, 5 kinds, with a "Contact angle" slider and the link key `ca`,
- "Color each region" (Off, By shape, Neighbours differ, 2 to 4 colours), link keys `rc` and `rk`,
- "Interlace" (over-under ribbons, ribbon width, gap), link keys `il`, `iw` and `ig`,
- a note in the Image tab: "You can trace an image made with any tool, AI included."

The region code, the interlace code and their two controls load on demand. The star code has no file of its own. It is in the `fractal` file, which the Patterns page loads at start.

## How to measure

Run `make perf`. It builds the site for production, serves it with `vite preview`, and runs Lighthouse (mobile) 3 times per page. The tables give the median.

Start JavaScript is the sum of the gzip sizes (default level) of the script and modulepreload files that each `dist/*.html` lists.

The "after" numbers come from the production build of commit `ba40fc1` (main after the phase 7 merge), on one machine, on one day.

```

| Studio | 99 | 1655 | 1881 | 27 | 0.000 | 105936 | 166 |
| Builder | 99 | 1520 | 1806 | 14 | 0.000 | 91746 | 107 |
```

`make perf` exited 0.

Lighthouse is noisy. The three Patterns runs gave script eval 309, 227 and 219 ms. Earlier runs on main, with no code change, gave a Patterns script eval from 275 to 388 ms (orchestrator's runs). The phase 7 median of 227 ms is inside or below that spread. So these numbers do not show a slowdown. They also do not prove a speed-up.

## Tile sizes

The orchestrator measured these, not this note's author.

- Star patterns: 0.2 to 0.6 KB gzip per tile.
- Region colours add 1.4 to 2.8 KB gzip on the star kinds, 5.6 to 6.8 KB on p4m, and about 48 KB on p6m.
- Interlace on `star-488` at depth 2 adds about 0.4 KB gzip.

## What the numbers show

Patterns loads about 2 to 2.5 kB more JavaScript at start. That is the star kinds in the `fractal` file, the new state, the link keys and the two control loaders.

A visitor who turns on region colours loads about 4 kB gzip (the control and the region code). Interlace costs about 4.5 kB gzip the same way. Before that, they cost nothing.

Region colours make a p6m tile much heavier (about 48 KB). The size badge shows this to the visitor.

The layout shift is 0.000 on the three pages. The scores are 95, 99 and 99.
